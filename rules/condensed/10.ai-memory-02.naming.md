## 各层命名

| 层 | 命名方式 | 示例 |
|----|---------|------|
| L1 | 固定名 | `00.overview.md`（唯一文件） |
| L2 | 分类编号 | `00.meta.md` `01.arch.md` `02.backend.md` |
| L3 | 编号 | `02.backend-01.api.md` |
| L4/standards | 编号（与L3对应） | `02.backend-01.api.md` |
| L4/adr | ADR序号 | `0001-database-driven-routing.md` |
| L5 | 日期编号 | `2026-04-13.task-fang-wallet.md` |

## Frontmatter（L2/L3 文件）

```yaml
---
description: "Vue component development rules"
globs: "**/*.vue"   # 可选，按需触发
---
```

只用 `description` + `globs`（可选），兼容所有工具。

## 禁止

- 文件名含大写（L0-L6 目录名除外）
- 文件名含下划线（用连字符）
- 文件名含空格或中文
- L2 目录内放非 `.md` 文件

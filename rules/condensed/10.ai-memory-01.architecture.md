# 10.ai-memory-01 AI 记忆体系架构（精炼版）

> Full spec: rules/standards/10.ai-memory-01.architecture.md

## 六层定义

```
L0  SPECS      项目进度管理   动态层              specs/workflows/hooks/templates
L1  OVERVIEW   启动引导       1个文件，≤100行      → AGENTS.md / CLAUDE.md 等（自动载入）
L2  INDEX      分类索引       11个文件，≤50行      → .kiro/steering/ 等（自动载入）
L3  CONDENSED  精炼规范       ~60个文件，≤200行    按需读取（不自动载入）
L4  FULL       完整规范       无限制               按需读取
L5  LOG        操作日志       无限制               回溯历史时
```

## 自动载入层

| 层 | 工具 | 目标 |
|----|------|------|
| L1 | 所有工具 | `AGENTS.md` `CLAUDE.md` `.cursorrules` `.windsurfrules` |
| L2 | 所有工具 | `.kiro/steering/` `.cursor/rules/` `.claude/memories/` `.continue/rules/` `.windsurf/rules/` |

**L3 不自动载入**，通过 `globs` frontmatter 按需触发。

## 蒸馏方向

```
L5（原始日志）→ L4（完整规范）→ L3（精炼）→ L2（分类索引）→ L1（概览）
```

L0 是独立动态层，不参与蒸馏链。

## 目录结构

```
.ai/
├── L0/specs/{active,backlog,completed}/  ← 功能规格
├── L1/00.overview.md                     ← 唯一文件
├── L2/{00.meta,01.arch,...,10.ref}.md    ← 11个分类索引
├── L3/*.md                               ← 精炼规范（与L4一一对应）
├── L4/{standards,references,adr}/        ← 完整规范
└── L5/{YYYY}/{MM}/*.md                   ← 操作日志
```

## 零容忍

- `.ai/` 内不放运维脚本
- L2 目录只放 `.md` 文件（Roo Code 会加载所有文件类型）
- 映射通过 `./gogogo.sh 8f`，不手动 `ln -sf`

# 元规范

> 详细规范：[standards/00.meta-01.core.md](../standards/00.meta-01.core.md)

## 文档体系

```
浓缩版（README.md）← 导航索引，≤1000行
   ↑
精炼版（condensed/）← AI读取，100-150行/文件
   ↑
完整版（standards/）← 人类阅读，无限制
```

## 规范文档命名格式

```
{大类编号}.{类别}-{序号}.{主题}.md
```

| 编号 | 类别 | 说明 |
|------|------|------|
| 00 | `meta` | 元规范 |
| 01 | `arch` | 架构规范 |
| 02 | `backend` | 后端规范 |
| 03 | `frontend` | 前端规范 |
| 04 | `quality` | 质量规范 |
| 05 | `biz` | 业务规范 |
| 06-10 | ... | 其他分类 |

**数字含义**：
- 第1段：大类编号（`02` = 后端）
- 第2段：类别内序号（`03` = 第3个主题）
- 第3段+：子主题序号

**举例**：
```
01.arch-01.core.md                  # 架构-第1个-核心
02.backend-03.db-01.tables.md       # 后端-第3个db-子主题01-tables
02.backend-03.db-03.field-02.order.md  # 更深层级
```

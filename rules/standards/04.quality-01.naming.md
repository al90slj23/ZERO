# 04.quality-01.naming - 命名规范

> **文档版本**：v1.0.0
> **创建日期**：2025-12-30

---

## 📍 文档定位

本文档定义了变量、函数、文件及 API 路由的命名规则。

---

## 🎯 核心原则

1. **语义清晰优先**
2. **一致性保证**
3. **点分命名法**（文件拆分场景）
4. **驼峰命名辅助**（代码内部命名）

---

## 📁 目录命名规范（强制）

### 核心原则

**所有目录路径一律使用小写**

```
pages/
├── admin/              # ✅ 小写
│   ├── users/          # ✅ 小写
│   │   └── config/     # ✅ 小写
│   └── orders/         # ✅ 小写
│       └── list/       # ✅ 小写
└── home/               # ✅ 小写
```

### 常见错误

```
# ❌ 错误：目录使用大写
pages/admin/Users/Config/

# ✅ 正确：目录全部小写
pages/admin/users/config/
```

### 例外情况

- `Scope/` 和 `Shared/` 目录使用大驼峰（职责容器规范）
- 这是唯一允许大写的目录命名场景

## 📄 文件命名规范

### 点分命名格式

```
FeatureName.FileType.ext
```

| 类型 | 格式 | 举例 |
|------|------|------|
| 视图 | `FeatureName.view.html` | `UsersList.view.html` |
| 逻辑 | `FeatureName.logic.js` | `UsersList.logic.js` |
| 样式 | `FeatureName.style.css` | `UsersList.style.css` |
| API | `FeatureName.api.php` | `UsersList.api.php` |
| 配置 | `FeatureName.config.js` | `UsersList.config.js` |

### FeatureName 生成规则

**核心公式**：**FeatureName = 路径最后两级目录名组合（大驼峰）**

| 目录路径 | FeatureName |
|----------|-------------|
| `/admin/users/list/` | `UsersList` |
| `/admin/orders/config/` | `OrdersConfig` |

### 子功能拆分

```
UsersList/
├── UsersList.view.html
├── UsersList.Create.view.html      # 创建功能
├── UsersList.Edit.view.html        # 编辑功能
├── UsersList.BatchUpload.view.html # 批量上传
```

## 💻 代码命名规范

### 小驼峰（camelCase）

**适用场景**：变量名、函数名、JSON 字段名

```javascript
const userName = 'John'
const userAge = 25

function getUserInfo() { }
function processOrderData() { }

{ "userName": "John", "orderAmount": 100 }
```

### 大驼峰（PascalCase）

**适用场景**：类名、组件名、接口名、FeatureName

```javascript
class UserManager { }
interface UserInfo { }
```

### 常量命名

**全大写 + 下划线**

```javascript
const MAX_COUNT = 100
const API_BASE_URL = 'https://api.example.com'
```

### CSS 类命名

**kebab-case**

```css
.user-profile { }
.user-profile-header { }
```

## 🐘 后端类文件命名

### PHP 特殊规范

**PHP 文件禁止使用点分命名**，必须使用纯驼峰：

```php
// ❌ 错误：PHP 文件不能使用点分命名
UsersList.Controller.php

// ✅ 正确：使用纯驼峰
UsersListController.php
```

**原因**：PHP 命名空间语法只支持反斜杠 `\` 作为分隔符

### 点分命名适用范围

- ✅ **可以使用**：HTML、JavaScript、CSS、配置文件
- ❌ **禁止使用**：PHP 类文件、Java 类文件

## 📡 API 路由命名规范

### 核心原则

使用冒号（`:`）表示自定义方法，避免与文件路径混淆

```
/api/{module}/{resource}             - 标准 RESTful
/api/{module}/{resource}:{operation} - 自定义方法（冒号）
```

### 符号语义

| 符号 | 含义 |
|------|------|
| `/` | 资源层级分隔符（真实目录） |
| `:` | 操作类型标识符（虚拟参数） |
| `-` | **禁止使用** |

### 举例

```
GET  /api/admin/users/list              - 获取列表
GET  /api/admin/users/list:123          - 获取ID=123 ✅
PUT  /api/admin/users/list:batchUpdate  - 批量更新 ✅
```

## 🗄️ 数据库命名规范

### 表命名

```
{业务域}_{子域}_{通用语义后缀}
```

| 后缀 | 含义 | 举例 |
|------|------|------|
| `list` | 主表 | `users_list` |
| `config` | 配置表 | `users_config_roles` |
| `log` | 日志表 | `users_log_login` |

### 字段命名（三段式）

```
{表级前缀}_{语义分类}_{字段名}
```

举例：`base_profile_nickname`、`base_status_active`

---

## 📊 命名风格速查表

| 场景 | 风格 | 举例 |
|------|------|------|
| **目录路径** | **全小写（强制）** | `pages/admin/users/` |
| 前端文件 | 点分命名 | `UsersList.view.html` |
| 后端类文件 | 纯驼峰 | `UsersListController.php` |
| 变量/函数 | camelCase | `userName` |
| 类名 | PascalCase | `UserManager` |
| 常量 | UPPER_SNAKE | `MAX_COUNT` |
| CSS类 | kebab-case | `user-profile` |
| 数据库表 | 下划线 | `users_config_levels` |
| 数据库字段 | 三段式 | `base_profile_nickname` |
| API路由 | 冒号语法 | `/list:export` |

## ⚠️ 常见错误避免

### 混用命名风格

```
# ❌ 错误
UsersList_FormLogic.js
UsersList-Form-Style.css

# ✅ 正确
UsersList.Form.logic.js
UsersList.Form.style.css
```

### FeatureName 不正确

```
# ❌ 错误
List.view.html                  # 只用一级
AdminUsersList.view.html        # 用完整路径
usersList.view.html             # 小驼峰

# ✅ 正确
UsersList.view.html             # 最后两级，大驼峰
```

# 02.backend-01.api - API设计规范（冒号语法）

> **文档版本**：v1.0.0
> **创建日期**：2025-12-30

---

## 📍 文档定位

本文档定义了 API 路由设计规范，采用**冒号语法**避免与文件路径混淆。

---

## 🎯 核心原则

### 铁律：斜杠仅用于真实目录

```
斜杠 "/" 左右必须是真实存在的目录层级
虚拟参数（ID、操作名）必须用冒号 ":"
```

**验证方法**：
```bash
# API路径中每个/后面的部分，必须能在文件系统中找到对应目录
ls pages/{每个/分隔的部分}/
```

---

## 📐 语法规则

### 1. 斜杠 `/` - 仅用于真实目录

**判断标准**：路径中每个 `/` 后的部分必须对应真实存在的目录

**举例**：
```
✅ /admin/users/config/levels
   → 对应目录 pages/admin/users/config/levels/ 存在

❌ /admin/users/config/levels/123
   → 目录 pages/admin/users/config/levels/123/ 不存在！
```

### 2. 单冒号 `:` - 虚拟内容（ID或操作）

**用途**：
- 资源ID（数字）
- 自定义操作（字符串）
- 任何非真实目录的参数

**举例**：
```
# 资源ID
GET    /list:123              # 获取ID=123
PUT    /list:123              # 更新ID=123
DELETE /list:123              # 删除ID=123

# 自定义操作
GET    /list:export           # 导出
POST   /list:batchDelete      # 批量删除
POST   /list:refresh          # 刷新
```

### 3. 双冒号 `::` - 子资源层级

**用途**：表示进入下一层虚拟子资源

**举例**：
```
# 一级子资源
GET    /list:123::orders           # 获取用户123的订单列表
POST   /list:123::orders           # 为用户123创建订单

# 二级子资源
GET    /list:123::orders:456       # 获取用户123的订单456
```

### 4. 禁用场景

```
❌ 斜杠用于虚拟参数
/list/123/orders          # 123不是真实目录

❌ 查询参数代替路径
/list?id=123&action=export

❌ 单冒号连接子资源（应该用双冒号）
/list:123:orders          # 应该是 ::orders
```

## 📡 API 路由举例

### 基础 CRUD

```bash
# 列表查询
GET    /api/admin/users/list

# 创建
POST   /api/admin/users/list

# 获取单个
GET    /api/admin/users/list:123

# 更新
PUT    /api/admin/users/list:123

# 删除
DELETE /api/admin/users/list:123
```

### 自定义操作

```bash
# 导出
GET    /api/admin/users/list:export

# 批量删除
POST   /api/admin/users/list:batchDelete

# 刷新缓存
POST   /api/admin/users/list:refreshCache

# 获取统计
GET    /api/admin/users/list:statistics
```

### 子资源操作

```bash
# 获取用户的订单列表
GET    /api/admin/users/list:123::orders

# 获取用户的特定订单
GET    /api/admin/users/list:123::orders:456

# 创建用户的订单
POST   /api/admin/users/list:123::orders
```

## 🔧 后端实现要点

### URL编码处理

由于部分后端框架无法直接识别字面冒号，需要 URL 编码：

```
字符：:
URL编码：%3A

转换举例：
/list:export → /list%3Aexport
```

### 路由定义注意事项

1. **冒号参数需要正则约束**：避免与其他路由冲突
2. **避免框架自动添加斜杠**：部分框架会在路由前缀后自动加 `/`

## 🔐 PHP API 认证规范

### 核心原则

每个 API 入口文件（`.api.php`）应该**自包含认证逻辑**，不要 require 其他完整的 API 入口文件。

### ❌ 错误做法

```php
// user.api.php
<?php
// ❌ 错误：require 了完整的 API 入口文件
require_once __DIR__ . '/../../main.api.php';  // main.api.php 会输出 JSON 响应！

// 这会导致输出两个 JSON 响应，前端解析失败
```

**问题**：如果被 require 的文件是一个完整的 API 入口（包含 `echo json_encode()`），会导致：
1. 输出两个 JSON 响应
2. 前端 `JSON.parse()` 失败
3. 难以调试的错误

### ✅ 正确做法

```php
// user.api.php
<?php
// ✅ 正确：只 require 库文件（.include.php）
require_once __DIR__ . '/../../../database.include.php';

header('Content-Type: application/json; charset=utf-8');

// ✅ 正确：自己定义认证函数
function checkAdminSession($token) {
    if (empty($token)) return false;
    $storedToken = getSetting('admin_session_token');
    return !empty($storedToken) && $token === $storedToken;
}

// 获取输入
$input = json_decode(file_get_contents('php://input'), true);
$token = $input['token'] ?? '';

// 验证认证
if (!checkAdminSession($token)) {
    echo json_encode(['code' => 401, 'message' => '未授权']);
    exit;
}

// 处理业务逻辑...
```

### 文件分类（行业通用命名）

| 后缀 | 用途 | 可以 require |
|------|------|-------------|
| `.include.php` | 库文件（函数/类定义） | ✅ 可以 require |
| `.api.php` | API 入口（输出 JSON） | ❌ 不要 require |
| `.controller.php` | 控制器类 | ✅ 可以 require |
| `.service.php` | 服务层类 | ✅ 可以 require |

### 认证函数模板

```php
/**
 * 验证管理员 session
 * @param string $token 前端传递的 token
 * @return bool 是否验证通过
 */
function checkAdminSession($token) {
    if (empty($token)) return false;
    $storedToken = getSetting('admin_session_token');
    return !empty($storedToken) && $token === $storedToken;
}
```

### 前端 Token 传递

```javascript
// 获取 token
function getAuthToken() {
    return localStorage.getItem('auth_token') || '';
}

// API 请求时传递 token
fetch('/api/admin/user.api.php', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        action: 'list',
        token: getAuthToken()  // 🔑 必须传递 token
    })
});
```

### 公开 API 与认证 API 混合

```php
// 定义公开 action 列表
$publicActions = ['getSiteInfo', 'getVersion'];

if (in_array($action, $publicActions)) {
    // 公开 API：可缓存
    header('Cache-Control: public, max-age=86400');
} else {
    // 认证 API：不缓存，验证 token
    header('Cache-Control: no-store');
    $token = $input['token'] ?? '';
    if (!checkAdminSession($token)) {
        echo json_encode(['code' => 401, 'message' => '未授权']);
        exit;
    }
}
```

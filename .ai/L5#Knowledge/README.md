# L5#知识检索与关联 (Knowledge)

> **版本**：v2.1.1
> **更新日期**：2026-10-23
> **状态**：可选的工具化查询层

## 定位

L5 帮助 AI 从已有资料中找到文档、定位源码并探索关系。知识正文归属 L0-L4，源码保留在原模块；项目知识源资料、适配配置、索引和模型缓存全部保存在 `.ai` 内。

```text
.ai 的原始文档 ──> QMD 文档检索索引 ─────────┐
                                           ├─> L5 查询 ─> 来源证据
项目源码 ───────> CodeGraph 源码关系图 ──────┘
```

| 适配器 | 默认用途 | 能力边界 |
|--------|----------|----------|
| QMD | `.ai` 的关键词、语义和混合检索 | 文本相似度不能表达通用实体/事件关系，也不能判断规范版本 |
| CodeGraph | 源码符号、调用、引用、继承和影响面探索 | 代码关系图不等于业务事实图，静态分析不能证明运行时行为 |

这两个工具共同覆盖文档检索与代码关联。通用实体、事件、时间关系，以及自动跨源关系融合仍需专门图谱工具；未来有明确查询需求时再接入，接入的数据必须保留来源和更新/删除规则。

## 维护方式

- 规范、事实与决策只维护其原始文件；禁止在本目录手工建立第二套 Markdown 知识图谱。
- QMD 从 `.ai` 生成索引，由 ZERO 适配器在启动和任务收尾时自动刷新；用户无需重复维护或手动同步。QMD 自身没有文件 watcher。
- CodeGraph 从源码建图；活动 MCP 会话自动同步，适配器启动时补齐离线变化。
- 配置和索引自动生成于 `.ai/L5#Knowledge/.generated/`，不提交；CodeGraph 仅需根 `.codegraph` 软链作为工具入口，真实文件都在 `.ai` 内。原始资料不能因重建索引而删除。
- 旧项目已有的 L5 文档按迁移指南归位，迁移时保留内容、历史与引用；检索缓存不承担唯一保存职责。

# ZERO v2.1 检索与关联层：设计

> 状态：completed
> 日期：2026-10-23

```text
.ai 原始文档 ──QMD──> .ai/L5#Knowledge/.generated/ 文档索引 ─┐
                                                          ├─> L5 查询 ─> 来源
项目源码 ──CodeGraph──> .ai/L5#Knowledge/.generated/ 源码图 ──┘
```

- L5 是查询能力的逻辑层；`.ai/L5#Knowledge/README.md` 说明边界，不存第二份事实。
- QMD 用命名 index `zero`，配置/数据库/缓存全部重定向到 `.ai` 内，集合仅收录原始 Markdown，排除生成物。启动与 Agent 收尾自动刷新。
- CodeGraph 数据存 `.ai` 内，根 `.codegraph` 软链由适配器自动生成；首次 `init`，活动 MCP watcher 增量同步，启动时补齐离线变化。
- 本地脚本和 hook 放在 L0，从目标项目根目录执行；只调用已安装 CLI。客户端一次性登记适配器启动入口，不调用可能修改 `AGENTS.md` 的自动安装器。
- 冲突顺序：L3 当前规范、L4 历史、源码现状分别按问题类型核验；检索排名不改变权威性。
- 未来通用实体关系工具必须能从 `.ai` 和源码重建，且有可验证的来源链接。

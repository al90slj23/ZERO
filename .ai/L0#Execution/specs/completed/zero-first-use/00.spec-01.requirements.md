状态：completed；日期：2026-10-23。

## 目标

ZERO 是新项目与既有非 ZERO 项目的初始化模板。首次引入必须完成知识源归位、项目规则适配、工具安装、索引构建与客户端连接，不能只复制规范后要求用户重复维护 QMD/CodeGraph。

## 约束

- `.ai` 是唯一维护源；项目配置、固定版本工具、本地模型和索引均在 `.ai`。根入口只是摘要或指针。
- CodeGraph 使用支持多对话的共享 daemon；用户目录进程登记与系统临时 socket 为自动运行元数据。
- 目标目录必须显式可判定；不能误用 ZERO 下载目录、覆盖已有业务部署脚本或执行旧的强制 IDE 映射。
- 修改前备份目标现有 `.ai` 和将改动的连接/入口文件，清单可恢复；既有唯一事实和更高优先级项目边界不得丢失。
- 已有项目规范、代码命名、路由与数据库差异由 Agent 审计和按迁移计划处理，脚手架不得假报业务改造完成。
- 重复执行不重复覆盖源资料、不重复追加指令或安装工具。
- 完成后提交并推送本 ZERO 仓库至负责人指定的 `al90slj23/zero`；不发布 ALV 业务服务。

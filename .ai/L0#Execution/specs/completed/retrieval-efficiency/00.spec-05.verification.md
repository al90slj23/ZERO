## Final policy recheck

After clarifying two concrete range/reuse gaps, two additional fresh agents completed the same tasks at equal 30/30 correctness with identical actual model/effort and unchanged source hashes. Old/final totals were 650,483 / 569,970 model tokens, noncached input 34,367 / 68,035, and output 2,356 / 2,735. Whole source files decreased 6 → 4 and visible returned characters 122,946 → 103,529. Search blocks stayed 3 → 3; file-read blocks increased 4 → 5. Elapsed time increased 122.407 → 154.602 seconds; read-only refresh remained 0 → 0.

Both samples' raw-token totals decreased, but the final sample used substantially more noncached input and output. Cache conditions were not controlled, so neither paid cost nor subscription allowance savings are established. Preserve the countervailing measurements rather than publishing a fixed saving percentage. No additional rerun was used to select a favorable result.

# Retrieval efficiency — requirements

Status: complete. Version: v2.1.2. Date: 2026-10-23.

Reduce repeated searches, whole-file reads and repeated refresh work while preserving the evidence and verification needed by the task. Knowledge sources remain in `.ai`; models, tool pins and the six-layer physical layout remain unchanged.

- Known paths/symbols use targeted ranges; unknown topics begin with small scoped lexical results, and code relationships use narrow CodeGraph queries.
- Reuse current, unchanged evidence still visible in the conversation. Limit result counts and excerpts before expanding the search.
- Batch changed source documents and refresh once at task completion; read-only tasks do not proactively refresh. Provide explicit repair for diagnosed index problems.
- Keep mandatory first-use context, project ownership/security/host rules, complete-file audits and actual business adaptation obligations.
- Validate correctness and actual work with comparable tasks. Do not promise a fixed token or cost saving.

# Retrieval efficiency — design

Status: complete.

The current retrieval standard owns detailed query budgets, evidence reuse, fallback and refresh rules. L1 and AGENTS contain short entry summaries; bootstrap generates the same project entry without replacing the project's existing rules.

QMD begins with `lex`, a scoped collection, three results and no reranking; callers escalate only for a concrete recall gap. CodeGraph begins with three files for relationship questions. Known source locations and missing context use bounded range reads. Returned current source is already-read evidence.

Runtime maintenance checks content/configuration/model state under its existing locks and skips completed unchanged work. Forced repair remains explicit. The MCP path keeps shared CodeGraph daemon coordination and catches offline changes without redundant initialization on every connection.

All generated state stays in L5, and no second hand-maintained document or snippet cache is introduced. Correctness, returned content, actual indexing work and cost are separate validation dimensions.

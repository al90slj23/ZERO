## 🚀 Kiro 项目配置

### 配置步骤

1. 按 [首次接入指南](../references/zero-first-use.md) 建立或合并 `.ai`，保留已有项目知识与规则。
2. 在当前 Kiro 支持的项目指令设置中引用 `.ai/L1#Overview/guide.md`，经 L2 定位所需 L3 规范；源文件继续由 `.ai` 维护。
3. 按当前 Kiro 的 MCP 设置接入 `.ai/L0#Execution/workflows/local/retrieval-indexes.sh` 的 `qmd-mcp` 与 `codegraph-mcp`，工作目录为项目根目录。
4. 工作记录归入 L0 当前规格或 L4 历史，修改 `.ai` 原文后由 Agent 自动执行适配器 `refresh`。

本版 bootstrap 的 `--client codex` 仅自动配置 Codex；Kiro 连接需按其实际支持的设置合并，本文不定义额外配置文件格式。

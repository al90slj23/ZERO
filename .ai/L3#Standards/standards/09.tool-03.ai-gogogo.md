# 09.tool-03 AI 记忆体系管理入口（精炼版）

> Full spec: .ai/L4/standards/09.tool-03.ai-gogogo.md

## 两个入口

```bash
./gogogo.sh 8f    # 建立所有映射（最常用）
./gogogo.sh 8g    # 移除所有映射
./gogogo.sh 8     # 映射管理菜单
./gogogo.sh ai    # AI 体系管理菜单
```

## 映射层级

| 层级 | 源 | 目标 | 方式 |
|------|-----|------|------|
| L1 | `.ai/L1/README.md` | `AGENTS.md` `CLAUDE.md` `.cursorrules` `.windsurfrules` | 单文件链接 |
| L2 | `.ai/L2/*.md`（排除 README.md） | `.kiro/steering/` `.cursor/rules/` `.claude/memories/` `.continue/rules/` `.windsurf/rules/` | 逐文件链接 |
| L3 | `.ai/L3/` | `.cursor/condensed/` `.claude/condensed/` 等 | 整目录链接（可选） |

**注意**：ZERO 不包含 L0 specs/hooks/skills 映射（通用框架）。项目使用时可自行扩展。

## 核心规则

- **逐文件链接**，不整目录链接（避免 README.md 污染上下文）
- **L2 自动载入，L3 不自动载入**（L3 通过 globs 按需触发）
- **禁止手动 `ln -sf`**，必须通过 `./gogogo.sh 8f`
- `gogogo.ai.sh` 双重角色：函数库 + 条件菜单（`BASH_SOURCE` 判断）

## 禁止

- `.ai/` 内放运维脚本
- L3 映射到 rules 目录
- 整目录链接
- 手动建立映射

## 🚀 CLI 项目配置

### 安装和配置

新项目与已有项目首次采用 ZERO，均按 [首次接入指南](../references/zero-first-use.md) 建立或合并 `.ai`。保留已有 `CLAUDE.md` 等指令内容，将项目规则维护于 `.ai` 后通过当前客户端支持的入口引用。

本版 bootstrap 使用 `--client codex` 自动配置 Codex。Claude Code 的连接按其当前 MCP 设置合并，分别调用 `.ai/L0#Execution/workflows/local/retrieval-indexes.sh qmd-mcp` 与 `codegraph-mcp`，工作目录为项目根目录；本文不规定客户端配置文件格式。

## 💻 CLI 工作流

### 基本命令

先读 L0 当前规格与 L1 项目入口，经 L2 定位相关规范，再实施和验证。使用 QMD 定位难找的文档，使用 CodeGraph 缩小源码关系搜索范围。实施记录写入所属规格，架构决定记入 L4；修改 `.ai` 原文后，任务收尾自动执行适配器 `refresh`。

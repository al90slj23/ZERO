## 六层定义

| 层级 | 名称 | 物理目录 | 职责 |
|------|------|----------|------|
| L0 | L0#工作执行 (Execution) | `.ai/L0#Execution/` | hooks、skills、specs、templates、workflows |
| L1 | L1#项目概览 (Overview) | `.ai/L1#Overview/` | 项目入口、关键约束、快速导航 |
| L2 | L2#规范索引 (Index) | `.ai/L2#Index/` | 分类索引、标题大纲、按需读取导航 |
| L3 | L3#完整规范 (Standards) | `.ai/L3#Standards/` | 当前唯一规范主版本及参考资料 |
| L4 | L4#操作日志 (Changelog) | `.ai/L4#Changelog/` | 历史操作、迁移记录与决策过程 |
| L5 | L5#知识检索与关联 (Knowledge) | `.ai/L5#Knowledge/` | 工具化查询层；目录保存接入说明，索引由源资料生成 |

L0-L4 保存人工或 Agent 维护的原始执行资料、规范与历史。L5 提供查询能力，默认使用 QMD 与 CodeGraph。`.ai` 是唯一知识文档体系；源码和外部系统证据仍是其各自行为/状态的来源。

## 读取与查询

先读取当前任务相关的 L0 规格和 L1 项目入口，经 L2 定位 L3 当前规范。L4 在需要追溯时按需阅读。L5 可在定位困难时辅助检索，结果回到对应原始文档或源码；它不是固定必读的另一份知识正文。

```text
L0 当前任务 / L1 项目入口 → L2 导航 → L3 当前规范
                                  ↘ L5 检索 → 命中的 L0-L4 / 源码
```

旧七层中的“L3 精炼规范”和“L4 完整规范”已合并为六层 L3 当前唯一规范。

## 自动载入层

| 层 | 目标 |
|----|------|
| L1#项目概览 (Overview) | `AGENTS.md`、`CLAUDE.md`、`.cursorrules`、`.windsurfrules` |
| L2#规范索引 (Index) | `.kiro/steering/`、`.cursor/rules/`、`.claude/memories/`、`.continue/rules/`、`.windsurf/rules/` |

L3 按需读取；L5 返回有限范围的候选与来源，避免把整套文档或图谱自动塞入所有上下文。

## 写入与蒸馏

```text
经核验的源码/系统事实、L0 执行结果、L4 历史经验
  → L3 当前规范或参考资料 → L2 导航 → L1 必要约束

.ai 原始文档 → QMD 派生索引 ─┐
                            ├─> L5 查询（只定位来源）
项目源码 → CodeGraph 派生图 ─┘
```

L5 的结果经来源核验后，按上述写入流程更新原始资料；不能直接以缓存或排名作为规范依据。只维护 `.ai` 内的知识源资料，L5 的配置和生成物也在 `.ai` 内自动构建与更新。L0 的执行资产必须遵守 L3。

## 目录与索引

```text
.ai/
├── L0#Execution/        # hooks / skills / specs / templates / workflows
├── L1#Overview/         # guide.md / README.md
├── L2#Index/            # toc.md / README.md
├── L3#Standards/        # standards / references / guides / adr / cases 等
├── L4#Changelog/        # 有日期的历史记录
└── L5#Knowledge/        # 接入说明 + .generated/ 自动配置/索引/缓存
.codegraph -> .ai/L5#Knowledge/.generated/codegraph  # 自动生成的入口指针
```

L5 名称由 v2.0 的“知识图谱”调整为“知识检索与关联”，物理路径继续使用 `.ai/L5#Knowledge/`。默认适配器没有合并成通用实体/事件/时间图。能力、配置和失效处理见 [检索与关联适配规范](./10.ai-memory-04.retrieval-adapters.md)。

## 约束

- 六层物理目录使用 `.ai/L#English/`；文档引用使用中英文完整名称。
- 新规范只写入 L3；L2 只做导航，不能维护第二套正文。
- L5 不新增手工知识正文，不要求人工维护图谱关系。
- 首次接入遵循 [首次引入指南](../references/zero-first-use.md)，由 bootstrap 保留式合并客户端入口；既有可选 IDE 映射须保留项目约束，工具安装器不能越过映射源文件。
- 既有项目迁移 L5 时保留事实与引用，参见 [v2.1 迁移指南](../references/migration-guide-v2-1.md)。

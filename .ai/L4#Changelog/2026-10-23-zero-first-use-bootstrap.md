# ZERO 首次引入与初始化入口

日期：2026-10-23；版本：v2.1.0。

## 决策与实现

新增 `zero-bootstrap.sh --target <project>`，支持新项目与既有非 ZERO 项目；`--prepare-only` 先建立受保护的知识/连接入口，Agent 完成项目适配后再运行完整初始化。原有业务部署脚本不参与模板复制。

已有 `.ai`、AGENTS、Git 忽略、Codex 连接及待迁移的 CodeGraph 库先备份，保留文件内容、模式与链接。默认使用共享 daemon，配置源、固定版本工具、模型和索引在 `.ai`；仅客户端入口和自动进程元数据位于其必需位置。

`runtime_ready` 与项目适配分别报告。适配完成由任务规格的完成状态与勾选清单派生，并支持 active → completed 归档，防止重复引入重建待办。L2 保留稳定导航。

通用运行层自动安装 QMD 2.8.3 / CodeGraph 1.6.2。完整 `init` 预拉三个本地模型，完成中文嵌入和代码建图；成功后生成自有模型 SHA256 校验清单，重复初始化完整校验后复用缓存。HF ETag 不充当文件 SHA256。MCP 与普通读取不进入该全量校验/预下载步骤。

首次入口拒绝 filesystem root/home 等危险目标，预检运行目录、数据库、锁与日志别名，避免写出项目存储范围。锁及后台日志不跟随外部链接。

L1 收敛为最小阅读入口；当前平台工作流去除其他项目专属栈要求和失效路径，首次引入统一引用新指南。模板示例不作为采用项目事实。

## 验证

- 40 项可移植离线回归：20 项首次引入、20 项运行生命周期与存储保护；不依赖网络或本机已安装检索工具。
- 隔离 TypeScript 旧项目真实 cold install、旧知识归位、备份与已有 Codex 配置保留通过。
- 真实 QMD 2.8.3 索引 70 份 Markdown、待嵌入 0；中文问题首条命中该项目事实入口。CodeGraph 1.6.2 的 MCP 返回示例符号及源码。
- 真实模型测试复用本机已验证缓存和元数据；其中一次缓存校验触发了官方重新下载。没有用模拟测试替代真实 MCP 验收，也没有把 fixture 的结果宣称为任意业务项目已完成改造。
- 发布前语法、ShellCheck、模板本地链接、diff whitespace 和远程仓库状态复核。
